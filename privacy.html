Privacy Policy

Hanoi Window (“HanoiLive”) · Last updated: October 11, 2026

Hanoi Window is a small, privately operated tool that runs on the channel owner’s own computer to manage a single YouTube live stream (a live camera view of Hanoi, Vietnam, with background music). It is not a public service and is used only by the owner of that YouTube channel. This policy explains what data the tool accesses and how it is handled.

1. YouTube API Services

This tool uses the YouTube API Services. By using it, the channel owner agrees to be bound by the YouTube Terms of Service. Data obtained through the YouTube API is also subject to the Google Privacy Policy.

2. Data the tool accesses

With the channel owner’s permission (Google OAuth, scope youtube), the tool:

  • creates and updates the owner’s live broadcasts and live stream (title, description, tags, privacy status, schedule);
  • reads the owner’s channel name and ID to confirm the connected account;
  • reads public live chat messages on the owner’s live broadcast (message text, author display name, author channel ID);
  • posts chat messages on the owner’s live broadcast (a greeting and short automated replies, marked with 🤖).

The tool does not access viewers’ private data, email addresses, subscriptions, or any data outside the owner’s live broadcast.

3. How chat messages are used

To write short replies in the viewer’s language, the text of new chat messages and the author’s display name are sent to Anthropic (the provider of the Claude AI model) for processing, together with public information about the stream (local time, weather, current song). Anthropic’s handling of that data is described in the Anthropic Privacy Policy. Messages containing links or spam are filtered out before processing.

4. Storage

  • The Google OAuth token and stream key are stored only on the owner’s computer, in files readable only by the owner’s account.
  • A log of the most recent 60 chat messages and replies is kept on the owner’s computer to monitor reply quality, and older entries are overwritten automatically.
  • No data is sold, shared with advertisers, or used for any purpose other than operating the owner’s live stream.
  • No cookies or tracking are used by this website.

5. Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Once access is revoked, the tool can no longer read or write any YouTube data. To have stored chat logs deleted, contact the address below; they will be deleted within 7 days.

7. Contact
